M2 grant trace (no defect). There are two grant points. `resolve_asset_abs_path` (lib.rs, `allow_image(&app, &resolved)` before returning) covers edit-mode widgets, read mode (walkTokens -> `ensureResolved`), session restore, untitled/scratch tabs (base = scratchpad dir) and images after Save As. For Save As, `markSaved` -> `redrawImages` changes the cache key (`filePath::rel`), so the link is resolved again against the new folder and granted. `save_clipboard_image` grants `target_path` after the write, which covers pasted images (`primeAssetCache`). On Windows the resolved path is mixed (`C:/notes\.assets\x.png`). `push_pattern` (tauri src/scope/fs.rs:94-146) rebuilds it from `components()` and also adds `canonicalize_parent(path)`, which is the `\\?\C:\...` form. `is_allowed` (fs.rs:420-445) canonicalizes the requested path when it exists, so the canonical pattern matches the request. One edge stays: if the file does not exist at grant time and is later created with a different letter case than the link, the match fails, because glob `MatchOptions` stays case-sensitive by default. That is minor and unprobed.

M3 guard trace (no defect). wry webview2 `add_NavigationStarting` passes the URI to Tauri's handler, which calls plugin `on_navigation` (tauri src/manager/webview.rs:614-626). The initial loads `http://tauri.localhost/` (Windows), `tauri://localhost/` (Linux/macOS) and `http://localhost:3000/` (debug) all match `app_url`. `about:` is allowed. New windows (ctrl/middle click) are denied, because with no handler wry calls `args.SetHandled(true)` (wry src/webview2/mod.rs:847-849). `<a href="http://asset.localhost:80/...">` is kept by the sanitizer, but the guard refuses it because `Url::host_str()` gives `asset.localhost`.
