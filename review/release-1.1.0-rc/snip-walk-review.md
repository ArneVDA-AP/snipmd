# Snip walk, nap and friend visit: review before the Windows test (RC 1a3e086)

Scope: RC src/pet.ts, src/petSprite.ts, src/pet.test.ts, src/titlebar.ts, src/tabs.ts, src/saving.ts, src/external.ts, src/diskState.ts, src/styles/main.css, docs/SPEC.md section 4 and section 14 decision 9, docs/ARCHITECTURE.md, tools/demo/snip-walk. Test plan: IN/TESTPLAN-WIN11-20261027.md.

Facts that frame the review:
- src/pet.ts, src/petSprite.ts and src/styles/main.css are the same in v1.1.0-4 and in the RC. Command: `git diff v1.1.0-4 1a3e086 --stat -- src/pet.ts src/petSprite.ts src/styles/main.css` prints nothing. (observed)
- The wake rule moved after v1.1.0-4. In v1.1.0-4, `markSaved` in src/tabs.ts line 511 called `petMoment('saved')`, so a reload from disk woke Snip. In the RC, only `writeFile` in src/saving.ts line 32 calls it. (observed, `git show v1.1.0-4:src/tabs.ts`)
- The check `npx vitest run src/pet.test.ts` passes: 23 tests, exit 0. (observed)
- The probe OUT/probe-pet-nap.test.ts has 6 tests. Each test asserts the defective behaviour, so a pass confirms the defect. Command from RC: `npx vitest run --root ../out --environment jsdom --globals probe-pet-nap`. Result: 6 passed, exit 0. (observed)

## What the Windows test should look at first

1. N2, plus an added variant: after a nap, type a word, wait about 1 s, type a word, wait 1 s. Risk: M1, Snip stays asleep after two saves within about 2 s.
2. Added step for the RC wake rule: after a nap, change a clean open note in another editor and return to SnipMD. Expected: the note reloads and Snip keeps sleeping; then Ctrl+S brings the friend. Risk: m12, the RC change is untested.
3. W1. Risk: M3, the "one cell per step, no jumps" expectation cannot hold at 50 ms sampling for a far tab; judge the jumps against the 1.4 s cap instead. Also measure each direction (at most 1.4 s).
4. CT2 at 125 % first, then 150 % and 200 %. Risk: m6, fractional placement at 125 % can blur cells during the walk; m8, Snip off the grid if the scale changes while Snip is away.
5. CT5. Risk: m5, the idle breath continues right after the setting changes; record whether it stops after the first moment.
6. N3. Risk: m3, the friend first finishes its walk-in before it leaves; and the end state "one Snip at home, no friend".
7. W5. Risk: two moments within milliseconds (both checks run in parallel, external.ts:127-130); the cut must start from the cell reached, with no jump home.
8. W3. Risk: the short walk (about 45 cells, 1.1 s) must be shorter than the capped W1 walk (1.4 s); the difference is about 275 ms, which 50 ms sampling can resolve.
9. W4. Risk: the click through Snip on the tab title (pointer-events none) and the 4 s worry.
10. W2. Risk: low; rounding can move Snip 1 CSS px towards the close button.
11. W6 and W9. Risk: low; the scrolled-out check and Show Snip off are sound in the code.
12. W8. Risk: low; 20 to 45 s glances give 2 to 6 in 2 minutes, and every window focus restarts the glance timer.
13. T3. Risk: M2, Snip parked over a tab title after a nap started during a moment; m10, Snip asleep while the user types in untitled tabs; m9, the friend's dash on a wide window.
