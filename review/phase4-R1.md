# Phase 4 review (R1), branch claude/phase-4

Scope: phase 4 commits dd75666 and 5f9151b (diff against 3d5aad0, the phase 3 merge). The local `main` ref is at phase 1 (fa21ba8), so `git diff main` also shows phases 2 and 3; those were only checked for regressions.

Probes (all in the session scratchpad, removed afterwards except the build output there):
- Rust probe crate on `snipmd-core` (`cargo run --offline`), one run on a cross-filesystem move (`/dev/shm` to `/tmp`, so `fs::rename` fails with EXDEV like a move from C: to a USB stick).
- Vitest probes run with a scratch config against the real `src/external.ts` and `src/saving.ts`, with the same mocks the project tests use.

Windows-only claims are marked inferred.
