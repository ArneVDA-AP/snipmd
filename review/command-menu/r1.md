## Checked and found holding
- A note cannot forge a Copy button or a live box. The per-render UUID token is checked, and a note's `data-code` / `data-task` attributes are removed. Highlighting writes only `textContent` and `tok-*` classes on the app's element.
- Ctrl+P alone is still blocked and Ctrl+Shift+P opens the menu (app.test). A held Ctrl+Shift+P or Ctrl+Shift+PageDown acts once.
- moveTab keeps closed tabs in place, and the session stores strip order.
- The new tok colours pass AA on the code background in both themes (computed: lowest 5.39 dark comment, 5.52 light number).
- The task warning bar uses the key `task:<tab id>`. The Copy failure goes through showError.
